# YuanAssist

Android 端《如鸢》/《代号鸢》游戏辅助应用。基于 Android 无障碍服务实现自动化，包含战斗脚本录制与跟打、日常任务自动化、脚本调试工具，以及作业站、招募记录等辅助功能。

> 当前版本 `1.1.6.41`（versionCode `52`）｜包名 `com.example.yuanassist`｜Android，仅 `arm64-v8a`

## ⚔️ 战斗版悬浮窗

战斗脚本链路的操作面板，包含两种核心模式和一个辅助工具面板。

**录制模式**

- 通过全屏输入层采集点击与操作，记录回合、步骤和动作
- 支持新增回合、撤销、清空、编辑表格中的动作
- 支持滑动节点：第一次点屏作为起点，「获取结束坐标」再次点屏采集终点，保存为 `SWIPE`
- 可导出为脚本

**跟打模式**

- 执行录制结果或导入的战斗脚本，支持开始、暂停、继续、停止，并显示当前执行状态
- 指令管理页支持「回合复制」：填写来源与目标回合区间（等长且不重叠）后批量复制动作与附加指令

**附加指令**

战斗脚本与攻略可以按回合 / 动作挂载附加指令（共 12 种类型），运行时按 `turn` 与 `step` 触发；未通过检测时复用现有的返回确认与重开分支。

| 指令 | 触发时机与判定 |
| --- | --- |
| 增加延时 / 缩短延时 | 对该节点延时按毫秒增减 |
| 执行暂停 | 在该回合开始或该动作后暂停运行 |
| 关卡自动导航 | 开战前自动进入指定关卡，支持洞窟与泰山府等目标配置 |
| 龙气检测 | 回合开始或动作间隔结束时扫描战斗卡片区域的龙气模板并统计层数，支持 `≥` / `=` / `<` 三种条件 |
| 庞统复制检测 | 动作间隔结束前 0.5 秒、结束时、结束后 0.5 秒各截图一次，取全局最高分映射到 1-5 号位比对 |
| 暴击检测 | 动作执行 1.4 秒后截图，检测红色伤害数字或暴击字样 |
| 阵亡检测 | 回合开始检测指定站位（1-5）角色是否阵亡，可连续配置多个站位 |
| 全灭检测 | 回合开始检测「再次挑战」模板，命中后点击并重开 |
| 橙星检测 / 紫星检测 | 回合开始检测结算界面的橙色 / 紫色辉光 |
| 向左切换目标 / 向右切换目标 | 在指定回合按配置次数切换目标 |

**辅助功能**

- 自动选人开关与角色配置
- 战斗锚点 / 定位调整
- 设置页「高级参数」：录制模拟与跟打执行分离的点击、滑动参数
- 键位修正：显示 `A`、`↑`、`↓`、`圈` 四个动作标记，拖动只保存对应的 y 值，x 仍由列位算法计算
- 悬浮窗右下角透明热区缩放，窗口左上角固定；横竖屏或窗口尺寸变化后重新计算坐标并重排标记
- 小窗最小化与恢复、设置入口

## 🏠 日常版悬浮窗

悬浮窗本体只包含拖动入口、动作按钮和关闭按钮，背后挂载整条日常自动化链路。

**可启动的工作项**

- 通用日常脚本（`DailyTaskPlan`）
- 鸟食运行时、主线 6-24 运行时、观星运行时
- 角色导入、星石拼图
- 框选 OCR、屏幕选点、脚本录制

悬浮窗图标点击回到对应日常页面，动作按钮执行或停止当前工作，关闭按钮停止当前工作并移除悬浮窗。

**一键日常**

- 只读取 `assets/daily_scripts/daily/` 下的内置脚本
- 多选后导入日常悬浮窗，按列表顺序逐个执行
- 单项失败不中断，全部结束后统一汇总失败项
- 记忆上次勾选的脚本、`历练` / `观星` 选项以及调试开关
- 调试模式开启后按脚本节点在屏幕上绘制 ROI 红框，可同时保存调试截图

**内置脚本**

| 脚本 | 说明 |
| --- | --- |
| 领取体力 / 领取月卡 | 常规领取流程 |
| 行囊派遣 | 进入据点后按固定坐标点击 |
| 送礼一次 | 单次送礼 |
| 历练 | 铜钱 / 经验 / 风火 / 地水 / 阴阳，五入口单选，默认经验 |
| 观星 | 观星一次 / 有月卡观星 / 无月卡观星，后两者默认 30 次且可修改 |
| 白鹄扫荡 | 扫荡流程 |
| 地宫扫荡 | 首次识别关卡坐标后复用，共扫荡 10 次 |
| 相见 | 相见流程 |
| 鸢报一轮 | 含「最多 / 前往收集」的一次性收取逻辑 |
| 密探升级 | 升级流程 |
| 家具互动 / 家具历险 / 家具打造 / 材料打造 | 据点与打造流程，识别不到当前页面时先尝试回到首页 |
| 密探特训 | 特训流程 |

## 📜 脚本系统

**执行引擎**

`AutoTaskEngine` 按 `DailyTaskPlan` 顺序执行节点，当前支持的动作类型：

| 动作 | 用途 |
| --- | --- |
| `CLICK` | 点击坐标 |
| `SWIPE` | 滑动，记录起点、终点与时长 |
| `MATCH_TEMPLATE` | 模板匹配 |
| `OCR` | 文字识别 |
| `SCREENSHOT_GROUP` | 一次截图内跑多个视觉候选（`ocr` / `template`），组级 ROI 共享，子项可覆盖 |
| `CLICK_LAST_MATCH` / `CLICK_LAST_OCR` | 点击上一次模板匹配或 OCR 的命中位置 |
| `SET_VAR` | 设置运行时变量 |
| `BACK` | 返回操作 |
| `RUN_SCRIPT_SEGMENT` | 加载并执行子脚本，支持裁剪与自定义钩子 |

**分支与退出语义**

- 节点通过 `on_success` / `on_fail` 跳转，支持变量分支
- `-1` 表示正常完成（`on_success` 与 `on_fail` 相同语义）
- `-2` 表示异常失败

**录制与编辑**

- `DailyScriptRecorderManager` 负责录制，录制点落在游戏区域外时会自动推荐 `top` / `bottom` 位置类型
- `RecordedDailyScriptViewerActivity` 负责查看、分支切换、编辑与导出

**运行时可调项**

- 繁体模式：节点级声明 `mode_overrides.traditional`，全局开关打开后替换对应的 `action` / `params`
- 日常全局延时：由节点自身延时、页面低配适应延时与全局延时叠加
- 模板覆盖：OCR 节点可生成 App 私有模板和延时增量，不修改 `assets` 中的原始脚本

## 🧰 调试工作台

`DebugWorkbenchCoordinator` 提供从单张截图中测试与调优的入口：

- 模板匹配与 OCR 单点测试，查看命中范围与分数
- 模板替换与恢复（保存到 App 私有目录，不改动仓库内素材）
- 延时增量调整，运行时按脚本 key 应用
- ROI 编辑：在完整截图上拖动区域、调整上下边缘、恢复默认
- 自动索引 `assets/daily_scripts` 下的视觉节点（含递归子目录与 `SCREENSHOT_GROUP` 子步骤）

## 📋 作业站与攻略

**发布与浏览**

- 发布 / 编辑本攻略：游戏版本（`ruyuan`：`1` = 如鸢，`0` = 代号鸢）、空格分隔的自定义标签
- 标签展示时会合并游戏标签、自定义标签与标题推断标签
- 未上传攻略原图时，可复用录制模式导出图生成表格封面

**脚本导入**

- 本站攻略与 MaaYuan 攻略详情的「导入脚本」统一走 `ACTION_IMPORT_SCRIPT`，服务侧先确保战斗版悬浮窗打开再导入跟打数据
- MaaYuan v3 作业中的 `Custom/BirdRestart` 转换为庞统复制检测，`Custom/DragonRestart` 转换为龙气检测，并绑定在对应的真实动作之后
- 附加指令随攻略保存、预览、详情展示与导入共用同一份 JSON

**云端脚本共享**

- 共享内容为日常录制脚本整包（bundle），通过 Supabase Storage 保存 zip
- 元数据由 Supabase 与 Edge Function `yuanassist-api-v3` 管理
- 支持云端脚本评论区、图片指引、管理员发布标签
- 首页入口红点与消息未读数共用 `get-home-badges` 请求

## 🎴 招募记录

**卡池目录**

- 覆盖如鸢与代号鸢两个游戏版本，按 `sortOrder` 降序排列，绣衣天下固定置顶
- 卡池入口为满宽 `3:1` 横向卡片：左侧按原图比例显示封面，右侧展示总抽数、出金数、平均出金、不歪占比
- 不歪占比按实际比例着色：不低于三分之二为金色，低于三分之二为红色，无出金记录为中性色
- 封面全部来自 CDN，首次进入时在后台下载到 App 私有目录并缓存，缺失项显示远程 URL 并继续下载

**抽卡记录**

- 手动录入：只允许选择绝密密探，可填 1-40 抽，支持如鸢 / 代号鸢、新出密探与当前卡池 UP 置顶标记、按名称模糊搜索
- 抽数徽章文字按 `0-10`、`11-20`、`21-30`、`31-40` 四档变化；底色与描边按是否 UP 二分
- 详情页包含「本期总览」和「绝密密探」两个页签；距离保底剩余抽数可编辑，删除记录后重算绝密、UP 与非 UP 次数
- 不接入 OCR，数据由 `GachaArchiveStore` 独立持久化

**本地存档与云端同步**

| 操作 | 行为 |
| --- | --- |
| 新建 / 切换 / 删除 | 多个本地存档，最后一个存档不可删除 |
| 上传 | 以 `(user_id, archive_id)` 覆盖对应云端记录，不影响其他存档 |
| 下载 | 只读取同一 `archive_id` 的云端版本，经确认后覆盖当前本地存档 |
| 拉取云卡池 | 手动拉取云端 `active` 卡池，写入独立本地目录缓存 |

## 🧩 其他功能

**🧮 修为计算**

- 上传背包截图后使用离线 OCR 归一化图片：横向比 `9:16` 更宽时裁掉居中黑边，其余情况按宽度缩放至 1080
- 从背包 Tab 附近扫描至图片底部并按四列识别：先识别材料名，再在名称上方独立截取数字 ROI 二次识别
- 覆盖 18 种修为材料，支持简繁归一化、人工校正数量
- 默认使用全部 12 个历练关卡，可为每类材料输入关卡与次数并快捷加入库存
- 材料数量、密探输入与上次背包预览会本地保存，重新进入自动恢复

**👤 角色导入**

`CharacterImportEngine` 负责截图、OCR 与命盘 / 练度 / 名称推断。

**🪨 星石识别**

- 本地链路：Paddle 检测框驱动划分 + 单格识别，名字与等级使用固定字典和 `级` 锚点解析
- 结果散图走本地 OCR，结果长图走云端 OCR，且需先完成散图识别

**🔍 OCR 与选点**

- 本地离线 OCR：`assets/ocr` 中的 PP-OCRv6_small ONNX 模型，由 Android ONNX Runtime 加载
- 云端 OCR：表格与星石链路共用 `OcrManager` / `OcrRouteManager`
- 框选 OCR：悬浮窗弹出可拖动、可缩放的选区，确认后识别并以悬浮对话框展示结果
- 屏幕选点：每次点击开始按钮重新打开遮罩，点屏复制坐标后只关闭当次遮罩，可连续取点

**🔄 版本更新与账号**

- 首页展示当前安装包版本与静默拉取的最新版本，手动检查更新后刷新
- 发现新版本优先走应用内下载，完成后拉起系统安装器，浏览器下载作为手动入口与兜底
- 部分入口（如招募记录）需要登录后才能进入，未登录时提供跳转到设备登录 / 创建用户流程

**⚙️ 全局设置**

- 日常版偏好集中在「我的 → 全局设置」：繁体模式、排除密探、日常全局延时
- 战斗版使用独立的设置页，两者互不影响
