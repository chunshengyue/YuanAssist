# 2级UI优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改悬浮窗、不改作业站 tab、不强行迁移调试页的前提下，把主界面之外的核心二级页面统一到新的 Compose 视觉体系中。

**Architecture:** 复用当前主界面已落地的 Compose 视觉语言，先沉淀二级页通用壳和基础组件，再按“工具页 -> 日常链路 -> 我的链路”三段迁移。业务逻辑、数据源、权限检查、页面跳转语义保持不变，只替换页面承载方式和界面组织；旧 XML/旧 Fragment 壳只在对应链路完全接通后再收敛。

**Tech Stack:** Kotlin, Android View system, Jetpack Compose, Material 3, existing `Activity` / `Fragment`, existing repositories and local storage.
